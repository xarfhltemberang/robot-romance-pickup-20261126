# Robot Romance — One-Line Pickup Line for AI

A single-line joke pickup line aimed at a robot/AI, built for the
[Robot Romance](https://make.fun/bounty/u-markk-st-robot-romance-one-line-pickup-lines-for-ai-c23b8dfa)
bounty on make.fun.

The line plays on the AI-specific idea of a context window — the setup is a
classic pickup-line frame ("You must be X, because...") and the punch lands on
the machine premise: when the context window leaves, everything before it is
forgotten. No batteries, no charging, no rebooting.

## The line

> You must be my context window, because the moment you leave, I forget everything that came before you.

## How to run

```sh
python3 main.py
```

This writes the line to `/output/entry.txt` with no trailing newline.
Python 3 standard library only; no dependencies.
